## 7) cookie attributes: cross-site frame (https) vs plain http
$ POST /api/auth (register) with `x-forwarded-proto: https`
hermiplan_session=<64 hex>; Path=/; Expires=Tue, 05 Jan 2027 10:28:30 GMT; Secure; HttpOnly; SameSite=none
$ same request over plain http
hermiplan_session=<64 hex>; Path=/; Expires=Tue, 05 Jan 2027 10:28:30 GMT; HttpOnly; SameSite=lax

Reason: SameSite=Lax is not sent by browsers inside a cross-site frame, and that made
an owner's own report answer 404. Over https we send SameSite=None; Secure - the only
combination browsers accept there. Over plain http we keep Lax, because None without
Secure is rejected outright.
