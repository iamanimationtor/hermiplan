## 7) cookie attributes: cross-site frame (https) vs plain http
$ POST /api/auth (register) with `x-forwarded-proto: https`
hermiplan_session=828a5c65150ad1fd499708f75780f602582df06dc23f2de1c91e858c3d11b9a1; Path=/; Expires=Wed, 30 Dec 2026 17:41:20 GMT; Secure; HttpOnly; SameSite=none
$ same, over plain http
hermiplan_session=cfae6398e0336737a319929ce0d676fb5806efa415496388b022ca792080efc1; Path=/; Expires=Wed, 30 Dec 2026 17:41:20 GMT; HttpOnly; SameSite=lax

Reason: SameSite=Lax is not sent by browsers inside a cross-site frame; that is what made
an owner's own report 404. Over https we send SameSite=None; Secure, the only combination
browsers accept there. Over plain http we keep Lax, because None without Secure is rejected.
