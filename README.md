# HERMIPLAN — Project Intelligence Platform

پلتفرم حرفه‌ای مدیریت، برنامه‌ریزی و تحلیل پروژه برای مهندسان، مدیران پروژه، پیمانکاران، مشاوران و دانشجویان.

**Created by Mohammad Shirmardi (محمد شیرمردی)**

---

## اصل محصول

**Simple Input → Smart Processing → Professional Output**

کاربر بدون نیاز به آموزش تخصصی، اطلاعات پروژه را وارد می‌کند؛ موتور محاسباتی تمام پیچیدگی‌ها
(مسیر بحرانی، شناوری، زمان‌بندی، تخصیص منابع، هزینه، تعدیل و ریسک) را مدیریت می‌کند و یک
گزارش مهندسی استاندارد و قابل ارائه تحویل می‌دهد.

## قابلیت‌های کلیدی

| حوزه | قابلیت |
| --- | --- |
| موتور پروژه | CPM/PDM، شناوری کل و آزاد، وابستگی FS/SS/FF/SF با Lag، محدودیت‌های زمانی، تقویم کاری و تعطیلات |
| پایش | EVM (PV/EV/AC/SPI/CPI/EAC/VAC)، پیشرفت فیزیکی، تشخیص تأخیر، سلامت پروژه |
| منابع | تخصیص روزانه، اوج تخصیص، بهره‌وری، شناسایی بیش‌تخصیص |
| بازار ایران | ۳۷ ردیف نرخ (مصوب ۱۴۰۵/۱۴۰۴ و بازار آزاد)، ضریب منطقه‌ای، بالاسری، سود، ذخیره احتیاطی، تعدیل ماهانه بر پایه کارکرد |
| استانداردها | فهرست‌بهای واحد پایه، شرایط عمومی پیمان، مبحث مقررات ملی ساختمان، PMBOK 7، ISO 21500/21502، AACE |
| قالب‌ها | ۱۰ نوع پروژه با فیلتر حوزه/پیچیدگی/مدت و ساختار WBS آماده |
| ورود سریع داده | افزودن با یک Enter، درون‌ریزی مستقیم از Excel/CSV (تشخیص خودکار ستون‌ها، اعداد فارسی، واحدهای هفته/ماه/ساعت، اتصال خودکار پیش‌نیازها) |
| ایمنی داده | واگردانی/انجام مجدد (۴۰ مرحله) با Ctrl+Z، ذخیره خودکار پیش‌نویس، تأیید پیش از جایگزینی قالب |
| تحلیل سناریو | What-if زنده: تأخیر فعالیت‌های بحرانی، تغییر سرعت اجرا و اثر نرخ تعدیل بر برآورد نهایی |
| کمک به کاربر | راهنمای گام‌به‌گام + واژه‌نامه ۱۸ اصطلاح مهندسی به زبان ساده |
| خروجی | ۷ فرمت: PDF (A4)، XLSX، XLS، CSV، JSON، MS Project XML، بسته کامل ZIP |

## معماری

```
src/
├─ lib/
│  ├─ engine/          # موتور محاسباتی خالص و deterministic (بدون وابستگی به UI)
│  │  ├─ calendar.ts   # تقویم کاری، روزهای کاری، تعطیلات، تبدیل offset↔تاریخ
│  │  ├─ schedule.ts   # مرتب‌سازی توپولوژیک، CPM، شناوری، تخصیص منابع
│  │  ├─ analysis.ts   # تجمیع کامل: WBS، مسیر بحرانی، EVM، ریسک، سلامت، KPI
│  │  └─ types.ts      # مدل دامنه
│  ├─ market/          # فهرست نرخ بازار ایران + موتور قیمت‌گذاری و تعدیل
│  ├─ standards.ts     # استانداردها و متدهای محاسباتی
│  ├─ report/          # موتور خروجی: gantt-svg، xlsx، zip، msproject، html، package
│  └─ templates.ts     # قالب‌های آماده پروژه
├─ components/         # UI (builder، report، charts، nav، logo)
├─ app/
│  ├─ page.tsx         # صفحه اصلی (RTL، ریسپانسیو، موبایل‌فرست)
│  ├─ builder/         # ویزارد ساخت پروژه (۶ مرحله)
│  ├─ report/[id]/     # گزارش A4 قابل چاپ + مرکز دریافت خروجی
│  └─ api/             # analyze، projects، market، export، auth، health
└─ db/                 # Drizzle ORM + PostgreSQL
```

## اجرا

```bash
npm install
npx drizzle-kit push     # ایجاد جداول
npm run build && npm start
```

تست موتور محاسباتی و ممیزی موارد مرزی:

```bash
npx tsx scripts/engine-smoke.ts          # مجموعه تست موتور (CPM، تقویم، EVM، قیمت‌گذاری)
npx tsx scripts/engine-verification.ts   # ۷۶ بررسی با مقادیر محاسبه‌شده به‌صورت دستی
npx tsx scripts/edge-case-audit.ts       # ممیزی ۹ بخشی موارد مرزی + هر ۵ مسیر خروجی

# یکپارچگی API، جداسازی کاربران، OTP و فایل‌های خروجی (نیاز به سرور در حال اجرا)
npx next start -p 3170 &
BASE_URL=http://localhost:3170 npx tsx scripts/api-integration.ts
```

## متغیرهای محیطی

| کلید | الزامی | توضیح |
| --- | --- | --- |
| `DATABASE_URL` | ✔ | اتصال PostgreSQL |
| `HERMIPLAN_MARKET_FEED` | ✖ | آدرس فید نرخ لحظه‌ای بازار (در صورت تنظیم، نرخ‌ها ادغام می‌شوند) |
| `HERMIPLAN_MARKET_FEED_KEY` | ✖ | توکن احراز هویت فید |
| `SMS_PROVIDER_KEY` | ✖ | فعال‌سازی ارسال واقعی OTP (در نبود آن، حالت نمایشی فعال است) |

## نکات کیفی

- محاسبات اصلی پروژه توسط موتور اختصاصی و **deterministic** انجام می‌شود؛ هوش مصنوعی منبع محاسبات نیست.
- تمام خروجی‌های عددی قابل ردیابی به یک روش استاندارد (CPM، EVM، تعدیل کارکرد ماهانه) هستند.
- رابط کاربری RTL، موبایل‌فرست و بدون نیاز به ثبت‌نام است؛ OTP تنها برای قابلیت‌های اختیاری.
- نرخ‌های بازار با ذکر منبع و تاریخ مرجع نمایش داده می‌شوند و برای کاربر قابل اصلاح‌اند.
